# 🎮 Tetris Game

A classic Tetris game implementation built with modern programming practices. This project recreates the timeless gameplay experience where players arrange falling blocks (tetrominoes) to clear lines and score points.

---

## 🚀 Features

* 🧩 Classic Tetris mechanics (tetromino rotation, movement, line clearing)
* 🎯 Score tracking system
* 🎮 Keyboard controls for smooth gameplay
* 🧠 Collision detection and grid management

---

## 🛠️ Technologies Used

* JavaScript / HTML / CSS

---

## 🎮 Controls

| Key            | Action       |
| -------------- | ------------ |
| ⬅️ Left Arrow  | Move left    |
| ➡️ Right Arrow | Move right   |
| ⬇️ Down Arrow  | Soft drop    |
| ⬆️ Up Arrow    | Rotate piece |
| Space          | Hard drop    |
| P              | Pause game   |

---

## 🧠 How It Works

* The game board is represented as a grid.
* Tetrominoes spawn at the top and fall automatically.
* Players can move and rotate pieces to fit them efficiently.
* When a row is completely filled, it is cleared and points are awarded.
* The game ends when pieces stack up to the top of the board.
